CI now builds and tests on Node 22.23.3, the newest Node 22, instead of 22.20.0. That lets the pending lint-staged 17 update install (it needs Node 22.22.1 or newer). The package's minimum Node stays at 22.13 for now, because raising it would stop `npm ci` on any machine still on an older Node 22 before anything actually needs the newer one.
