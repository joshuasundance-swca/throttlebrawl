Picking a region shows its roads sooner again. Since the last fix the game asked the game server for a region's map files 4 at a time, which made San Francisco's routes take 3.4 to 4.4 seconds to show instead of 1.5, and the server never once asked it to slow down in the last live check. The game now asks for everything at once, and slows to 4 at a time only after the server says "too many requests", easing back once it has been quiet for 30 seconds. A first visit also downloads one or two vehicle models less, and the Keys' road data the game loads at start-up now gets the same care as everything else: it waits when the server asks, is tried again when it fails, and is read from the saved offline copy when there is one.
