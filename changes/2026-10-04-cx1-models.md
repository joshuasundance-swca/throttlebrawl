Every Blender model is now about a third smaller. The 35 existing models drop from 933,708 to
600,564 bytes with exactly the same triangles, faces and node names. A new step in the model build,
`tools/blender/optimize.mjs`, leaves out the stored normals (the game already rebuilds them from
each face), shares vertices between a model's colours and packs the file tightly. Rebuilding a
model still gives the same bytes every time.

The build also now checks that every face of a closed part points outward before export. All 35
existing models already passed: the README's old warning about faces wound backwards on the tow
truck, boat and palms did not hold up when re-measured, so it is gone.

New, for the traffic work that follows: eight shared traffic vehicles (sedan, hatchback, pickup,
SUV, minivan, box truck, city bus and a semi with a roof fairing), each one mesh with its wheels,
a marked hood for wheelie launches and white paint the game tints per type, and a parked car-hauler
trailer with its ramp down, built to the tow truck's ramp numbers. Nothing in the game uses them
yet; a later change swaps them in for the box cars.

Codex scripted the models and the optimiser; the coordinator re-checked them and fixed the sedan's
side windows (their corners folded over the pillars) and the semi's cab, which read as a car.
