The credits page no longer has the build label sitting over its last line on a phone held sideways, and it no longer thanks the U.S. Census Bureau for TIGER road data the game does not use. Every road in the game is baked from OpenStreetMap, with USGS elevation, and those are the two credits the page shows for map data.

For devs: playtest 4 run C's live check (punch item 11). Two causes. The label: `src/ui/index.ts` wrote the credits screen's bottom padding as `#credits`, which `#ui .screen` out-ranks, so the room that keeps the list above the build stamp was never applied; it is now `#ui #credits`, and the room scales with the text size and the bottom safe area. The TIGER line: it came from the base pack's `tiger-*` licence rule, which has no file under it (checked: no `tiger-` file in `packs/`, and every `provenance.sources` entry in the baked roads is OpenStreetMap or USGS 3DEP). `scripts/credits.mjs` now credits a licence rule only when a baked file of the pack matches its `paths` (`ruleIsUsed`), so the rule stays in `pack.json` and the page credits TIGER as soon as a `tiger-` road is baked (checked by dropping a `tiger-` file in: the line appears). A rule whose licence file is missing still fails the build. `THIRD_PARTY_ASSETS.md` needed no change: it already logs OpenStreetMap and USGS 3DEP and never listed TIGER. Tests: `scripts/credits.test.ts` (a rule with no baked file is left out and one with a file is credited; the repo case reads every pack file on its own and expects each rule's text on the page exactly when a file falls under it, and no census words while no road is baked from it; checked failing on the old builder first), and `tests/e2e/ui-screens.spec.ts` (the painted words of the credits list against the stamp's box at 915x412, 740x360, 640x360 and 568x320, at the top, the middle and the end of the list, with a planted-padding control that must find the last line under the stamp). The browser case was not run on the dev machine; CI runs it. Docs: `docs/content-packs.md`, the credits bullet. No change to first-load JavaScript beyond a few CSS bytes.
