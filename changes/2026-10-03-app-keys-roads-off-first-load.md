Main was red: the first-load JavaScript measured 501.9 KB gzip against its 500 KB budget, the fourth crossing in a day, each made by the last of several merges that fit alone (this time the career's show, #372, and the scenery merge, #377). This frees about 100 KB for good instead of a few: the Keys' hand-made road data (the keys-m1 network, its 19 roads and 3 routes, 23 files) no longer rides in the first-load JavaScript. It ships beside the build as JSON files, like a region's roads and the Keys' real roads, and the page fetches it before the app starts (it tries once more after a moment if that fails, then says so beside the build stamp). First-load JavaScript drops from 501.9 KB to 398.7 KB gzip (101.3 KB headroom), measured with `vite build` and `node scripts/perf.mjs --size-only` on the dev machine. The budget is unchanged.

The bytes still download before the first screen, as before, but as data the browser parses with `JSON.parse` rather than as JavaScript it has to compile, at the cost of one more round trip before the start screen. What a player sees does not change. The bundled base pack's files and their order are the same, so the sim content hash and every replay key hold: the build's baked self-test hash is the same before and after (99c3496b), and the sim chunk's name (its code hash) did not move.

Node-side readers of `loadBasePack()` get the same files from disk: a Vitest setup file (`tests/setup/base-roads.ts`, added to `vitest.config.ts`, which only this change needs) and the build's self-test race (`scripts/selftest-race.ts`) call `provideBaseRoadsFromDisk()`. Read before the roads are in, `loadBasePack()` throws a plain error rather than building a base without its roads. `src/content/base-pack.test.ts` checks that the 23 files are fetched once each and that the bundled base equals the pack as authored without its real roads; `scripts/first-load.test.ts` now fails if any pack's road data is bundled into the first load (it found 23 such files before this change). docs/content-packs.md records the move (a `[default]` that said the hand-made roads stay bundled). Not phone-verified; the browser tier runs in CI.
