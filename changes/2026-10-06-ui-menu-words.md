Three small fixes to the words on the menu. While a region loads, "Loading San Francisco" is now said once, not twice: the dimmed word under the spinner steps aside while the busy line is up. At the largest Text size the menu always shows its build id now (before, the footer and the corner stamp both gave way as soon as the menu scrolled, so it showed nowhere): it is the last line of the menu's column, shown whenever the menu scrolls, and it never lies over a control. And when the game server asks for a wait, the menu's word says how long ("Tap Race to try again in 27 s", the same seconds as the card's Retry button); after a "this build's files are gone" answer it has a Reload button beside it instead of only saying to reload.

For devs: `routeNoteQuiet`, `WAIT_SLOT`, `withWait` and `waitSeconds` are in `src/ui/transient-cards.ts` (`retryButton` counts with `waitSeconds` too, so the card and the word never differ); `setRoutesNote(text, action?)` fills the slot from the card's `retryWaitUntil` on the card's own timer, and `routesNoteView` in `src/app/load-retry.ts` gives a missing build the Reload action (`#route-note-action` in `src/ui/routes.ts`). The menu's `#menu-build-line` is decided in `keepFooterClear` with the line taken out for the measure (and the scroll put back), so it can never be what makes the menu scroll; `buildIdFindings` in `src/ui/screen-fit.ts` judges it. Unit tests (with controls) are in `transient-cards.test.ts`, `screen-fit.test.ts` and `load-retry.test.ts`; `tests/e2e/ui-transient-cards.spec.ts` counts the lines saying "Loading San Francisco" under the busy line (negative control: the word drawn too gives 2), compares the word's seconds with the card's, checks the Reload button and the wait at every size and Text size with the fit and in-view checks, and finds the build id at every size and Text size (negative control: no footer, stamp or line gives "the menu shows no build id"). `docs/architecture.md` ("Transient cards") is updated. Not phone-verified; the browser specs run in CI only (no local browser, per AGENTS.md).
