The menu has a Credits button. It lists where the maps come from (OpenStreetMap contributors and the U.S. Geological Survey, with a link to the map licence), every model, picture and voice in the game with a plain "AI-made" label on the ones AI made, and the licence texts, which open right on the page. It reads on the smallest phone held sideways.

For devs: there was no credits page before this (roadmap M5, credits-1), so this builds it and adds the rule test. `scripts/credits.mjs` (new) writes `dist/credits.json` in the build (a Vite plugin, so the offline worker caches it with the rest) from `THIRD_PARTY_ASSETS.md` (every table row, wherever it sits; a row that is not five cells, or whose AI cell does not start with Yes or No, fails the build), the packs' `licenseRules` and the `provenance.sources` credits in the baked road files, the licence files the rules name (the build fails on a missing one, or on a road source whose licence has no text), the repo's MIT licence and each shipped npm package's own licence file. `src/ui/credits.ts` (new, pure) reads the file and says what the page shows (`creditsView`, `viewText`); `src/ui/credits-screen.ts` (new) draws it, as a lazy chunk the menu's Credits button loads on first tap; `src/ui/index.ts` adds the button, the host and its CSS (first-load JavaScript 465,301 to 465,788 bytes gzip, +487, so about 34 KB under 500 KB; the page and its 54 KB data file are not in the first load). The rule test is `scripts/credits.test.ts`: it reads the ledger on its own and fails when a row is dropped, reordered or reworded on the page, when an AI-made row loses its label or a human-made one gains it, when a pack attribution or a road file's credit is missing, when a licence file the packs name is not on the page byte for byte, and when a shipped npm package has no licence text (checked by deleting the first entry: two tests fail). The browser check is a new case in `tests/e2e/ui-screens.spec.ts` at 568 by 320: the Credits button fits the menu, the page lists as many entries and AI labels as `credits.json` holds, shows the OpenStreetMap link, opens every licence text and fits with them open (not run on the dev machine; CI runs it). The ledger fixes: `THIRD_PARTY_ASSETS.md` had a blank line and a paragraph in the middle of its table, so GitHub rendered 11 rows as plain text (now one table, notices after it), and the two app icons (`public/icon-*.png`, code-drawn by an AI agent in run B) were not logged (new row, labelled AI-made). Not covered: how the page looks on the phone (done, not phone-verified); the TIGER credit comes from the base pack's rule although no TIGER road is baked yet.
