Develop one complete playable improvement under one integration owner. Internal interfaces and
their callers can ship together; independent risk or consumers can still justify separate PRs.
The optional worker workflow now returns unpublished contributions for one feature PR by default,
with explicit separate delivery available. Focused visual debugging can use the coordinated browser
slot before the final served check. Routine work needs a short acceptance list and one closeout.

Claude and other agents use the same tracked rules, including on recovery. The next chosen road
prototype trials these defaults using existing evidence. CI, hooks, budgets and the train are unchanged.

The workflow tests retain ownership, identity, dependency ordering, failure recovery and actual
CI/entry-point controls. They add integrated/separate delivery and invalid-choice controls. Prose
assertions for exhaustive policy wording and historical rationale are retired: those explanations
are reviewed with the change, not treated as executable safety guarantees. Contributor link and
configuration-consistency checks remain. This does not establish live Claude adoption or phone acceptance.
