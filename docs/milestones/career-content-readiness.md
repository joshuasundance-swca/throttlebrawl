# Career roads remain ready across menu actions

`[default]` A successful regional background road load must become available to the app even if the player selects another career tab or event while it finishes. That content completion must not replace the screen the player chose. Measurement preparation still retires its content generation; an ordinary career action does not.

## Automated acceptance

- Hold successful PNW road responses during a fresh, unlocked career visit. Prove that requests are actually held and its map is not yet drawn.
- Switch to Garage while loading, then release the responses. Successful background completion leaves Garage visible.
- Returning to Map shows its rendered roads, and riding the existing Ferry Line starts the qualified PNW route with no page error.
- Drive readiness by transport completion and rendered state, never a timed sleep or frame count. Read the request set and route from the content pack rather than copying a fixed file count.
- Preserve ordinary screen ownership, measurement content retirement, active-race replay keys and the existing retry controls. Run the normal gate and a served early-action check.

This repairs a served launch failure; it does not relax the separate cached-startup timing target or establish phone performance.
