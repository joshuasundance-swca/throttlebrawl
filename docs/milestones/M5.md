# Milestone 5: launch polish

> **In plain words.** Milestone 5 gets the game ready to show people. It must run smoothly on the maintainer's Galaxy A16 for a long session, so agents add quality levels and a picture that sharpens or softens itself to hold the frame rate, plus a one-tap test that rides for 15 minutes and reports the numbers. The rest of the accessibility options arrive, the first minutes of play get polished, and the game works offline and can be installed like an app. The game gets its real name. The repo has been public since its first push, after the first leak audit and with a quick leak scan on every commit; before anyone is pointed at the game, one more full sweep checks every file, every past commit and the hosted copies for anything private. A credits page lists every data source and licence. Then the maintainer checks the launch bar themselves: does it feel good, look distinctive, run well on the A16, and have personality? Only they decide when to share the link.

## The leak audit

The decided audit ("audit before public") ran before the first push to the public repo, and a quick leak scan runs on every commit ([the engineering doc](../engineering.md#pre-commit-hooks-and-leak-scan)). [decided] M5 adds a second, pre-launch sweep over the whole tree, the whole history and the Spaces, because the launch is when people are first pointed at the game. [default]

- **Whole tree and whole history.** `leakscan:all` over every tracked file, then over `git log -p` for every commit, with the generic rules in the repo and, on the maintainer's machine, their private denylist from user-level git config ([the leak scan](../engineering.md#pre-commit-hooks-and-leak-scan)). [default]
- **Beyond git.** The game Space's and staging Space's current files, the dataset repo's files and card, release notes and PR text. [default]
- **Public-safety sweep.** No "Road Rash" in any name or branding [decided]; no real people, brands or agency insignia in content or art; every non-original asset in `THIRD_PARTY_ASSETS.md`, and every AI-generated one labelled. [default]
- **If it finds something.** Stop and ask the maintainer. AGENTS.md bans agents from force-pushing and from rewriting published history, so what to do with a finding in an old commit is their call, made at the time. [default]
- **Report what it examined.** The audit prints the number of files, commits and bytes it checked, because a scan that looked at nothing reads like a pass. [default]

## The real name

The game gets its real name before M5 [decided], picked by the maintainer from M4's shortlist.

- **In the game:** the app-id constant in `platform/`, the title, the menus, the tone guide's references and the docs. Storage keys are name-neutral, so the only migration is reading the old key once. [default, per [the architecture doc](../architecture.md#design-principles)]
- **The repo and the Spaces:** renaming anything public needs the maintainer. [decided] Renaming a Space changes its URL, which loses every local save and install on the old address; the export code carries a career across ([deploy](../engineering.md#deploy-game-space-and-staging-space)). So the Spaces are not renamed: new Spaces are created under the real name, and the old game Space becomes a one-page "we moved" link to the new address. Nothing is deleted. [decided] (`milestones-rename-hosting`, cockpit answer, 2026-09-29) Creating the new Spaces is confirmed with the maintainer at the time, the old staging Space stops receiving deploys and gets the same link page, and the deploy workflows and Trusted Publisher claims move to the new Spaces in one infra PR. [default]
- **The streaming outfit's name** is picked before the launch, and checked for real-world clashes. [default, per [the tone guide](../tone-guide.md#other-writing-surfaces)]
- **A changelog notice** tells the player what changed, and how to move a save with the export code if the address changes. [default]

## M5 exit and the launch bar

### Automated exit criteria

From [the roadmap](../roadmap.md#m5--launch-polish): the perf gates hold; the soak tool writes its report; a browser test loads the game with the network off; the pre-launch leak sweep finds nothing across the whole tree and the history; and the rename migration test reads the old storage key once and moves it. Plus the whole gate green with nonzero counts, and the build live on the game Space. [default]

### The launch bar

A public v1 launch needs all four, judged by the maintainer. [decided] How each is checked is [default], from [the product spec](../product-spec.md#the-launch-bar):

| Bar | What the maintainer checks |
|---|---|
| **Feel** | Steering, hits, kicks, steals, crashes and takedowns feel right on the phone, and a tuning preset is locked in |
| **Look** | The look test has chosen a style, and the game has a recognizable visual identity |
| **Runs well on the A16** | The soak report: over 15 minutes at the largest field, excluding loading holds, the 95th-percentile frame time stays within the target frame interval (the display's refresh interval at the default full-rate setting: 11.1 ms at 90 Hz, 16.7 ms at 60 Hz [default]; 16.7 ms is the floor of the maintainer's "60 frames per second or better" [decided]; the frame-rate priority is smooth first [decided], so the bar is measured at the default setting, not the battery saver), the slowest 1 % of frames stay at 30 fps or better, and minute 15's median is within 10 % of minute 1's. Measured on the phone itself, never on desktop emulation |
| **Personality** | Rivals, barks, signs, billboards and interludes make the maintainer laugh, with no open vetoes |

### The phone playtest

The launch bar itself. Run the soak and paste the report. Then, if all four pass, the maintainer decides whether and where to share the game Space link. That outward step is theirs alone. [decided]

## Risks

- **Thermal slowdown on the A16.** A web page can't read the phone's temperature, so the soak uses minute-15 against minute-1 as the proxy. [default, per the product spec]
- **The rename can cost saves.** Handled by the decision below and the export code.
- **A leak in old history.** Agents can't rewrite history, so a finding goes to the maintainer. The repo has been public since its first push, so a finding in an old commit is already exposed, which is why the per-commit scan matters more than this sweep.
- **The replay viewer** is the first M5 item to move after v1 if time is short. [default]
