# Competition development decision, 2026-10-10

This is development authorization, not a new phone playtest.

The maintainer approved the recommendation with "Please proceed as recommended." `[decided]` The recommended sequence is Quick Play access to existing Race, Hunt, Escape and Grudge events plus stronger personalities for a representative set of bikes, followed by a focused boss prototype. Voices and regional scenery remain subsequent creative work.

The [competition depth milestone](../milestones/competition-depth.md) defines this batch's implementation and automated acceptance. Its technical choices are `[default]`. Existing objective kinds are exposed rather than new modes invented. Bike handling should give reasons to switch beyond top speed; this batch tests acceleration, steering, braking and contact stability using existing handling fields. Bike-specific stunt physics remain a later seam.

Phone feedback can steer this work without blocking development. The existing CI gate and one served-build check establish developer acceptance; neither substitutes for the maintainer's phone verification or authorizes a public launch announcement.
