# Road development direction, 2026-10-15

This is development direction from the maintainer, not a phone playtest or acceptance of the new courses.

## Locations and sequencing

The maintainer clarified the intended destinations:

> idk I think I'm interested in most of the ideas and candidates and almost certainly Kelso/Longview and Clinton. should we aim for more parallel work or should we proceed sequentially to learn and build off each other or what? maybe do common requirements beforehand? idk I just want to be clear about what I am already wanting lol

The coordinator recommended a short shared foundation, parallel owners for the first Longview and Clinton courses, and staggered integration so the first working ride informs the other. Longview extends the existing Pacific Northwest region; Clinton starts with a bounded course and minimal regional content. This is not a competition that eliminates one location.

The maintainer approved proceeding:

> Alright, cool. Be sure to manage this well so that a lot of work gets done quickly with minimal cicd/merge friction. Maintain project standards etc but be cautious about hard-coded limits in tests, testing implementation details, things like that. Let me know if anything if you have questions. Thanks :)

`[decided]` Develop both locations with shared requirements handled once and parallel location ownership. Maintain the existing engineering gate and test player-visible behavior and authored contracts rather than fixed content inventories.

`[default]` First deliveries use existing Race rules, one traversal, existing cast and assets where useful, and early rough playable courses before further scenery or regional career expansion. Actual source geometry may change which alignment comes first. Subsequent park routes, bridges and additional courses remain opportunities rather than prerequisites.

The [roadmap](../roadmap.md#regions-alongside-the-milestones) records how this advances beyond the earlier new-region hold for Clinton while preserving unrelated holds.
