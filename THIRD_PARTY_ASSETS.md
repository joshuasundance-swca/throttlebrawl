The concept sheets for the truck, boat and palms were made with the Codex CLI's built-in image generation for the trial. They are not in the repo; the models are new geometry, written as code and not traced from the images. Every Blender model is rebuilt from its script (see [tools/blender/README.md](tools/blender/README.md)).

The spoken barks carry two notices from their models. Kokoro-82M's model card lists Creative Commons training data: Koniwa (CC BY 3.0) and SIWIS (CC BY 4.0); the rivals' reference voices come from Kokoro, so that attribution is repeated here. Every Chatterbox output carries Resemble AI's inaudible "Perth" watermark, which marks the audio as AI-made. Chatterbox's preset voices (and its default reference) were never used: each clip's only reference is a Kokoro read made for that rival. The 9 clips redone in run W-S are Kokoro's own output, so the same CC BY attribution covers them. The listening check that picked them used Whisper large-v3-turbo (MIT) and large-v3 (Apache-2.0) and Microsoft's WavLM base-plus-sv speaker model (its model card carries no licence tag), locally, only to judge the clips; none of their output is in the game.
