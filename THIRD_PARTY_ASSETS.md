non-commercial and no-derivatives licences (see [AGENTS.md](AGENTS.md#public-safety)).

The concept sheets for the truck, boat and palms were made with the Codex CLI's built-in image generation for the trial. They are not in the repo; the models are new geometry, written as code and not traced from the images. Every Blender model is rebuilt from its script (see [tools/blender/README.md](tools/blender/README.md)).

The spoken barks carry two notices from their models. Kokoro-82M's model card lists Creative Commons training data: Koniwa (CC BY 3.0) and SIWIS (CC BY 4.0); the rivals' reference voices come from Kokoro, so that attribution is repeated here. Every Chatterbox output carries Resemble AI's inaudible "Perth" watermark, which marks the audio as AI-made. Chatterbox's preset voices (and its default reference) were never used: each clip's only reference is a Kokoro read made for that rival.

Everything else in the build so far is original or made in code.
